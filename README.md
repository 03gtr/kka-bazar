# KKA BAZAR — Digital Brand Card

 premium، mobile-first digital brand card لـ KKA BAZAR (هيبر ماركت).

## فكرة المشروع

عندما يمسح العملاء الـ QR الموجود على أكياس التسوق، يدخلون فوراً إلى الهوية الرقمية لـ KKA BAZAR — تجربة تشبهurar بطاقة تعريف تجارية تفاعلية، وليست موقع تسوق تقليدي.

## الصفحات (شرائح)

1. **الرئيسية** — الهوية والشعار والشعار الصوتي "كل احتياجاتك.. بمكان واحد"، بطاقة QR، وأزرار الاتصال/الموقع/اكتشف/عروض.
2. **اكتشف** — بطاقات فئات المنتجات (معلوماتية فقط، بدون أسعار أو منتجات وهمية).
3. **تواصل** — هاتف، وسائط اجتماعية (إنستغرام، فيسبوك، سناب شات، تيك توك)، والموقع (placeholder حالياً)، والعروض (placeholder).

## الألوان

المستخلصة من الأصول الأصلية للعلامة:

- Teal: `#008080`
- Teal Dark: `#006060`
- Orange: `#e06020`
- White / Offwhite

## الهيكل التقني

- `index.html` — التطبيق بالكامل (SPA داخل صفحة واحدة، ثلاث شرائح).
- `styles.css` — كل التنسيق.
- `script.js` — التنقل بين الشرائح وتفاعلات بسيطة.
- `assets/logo.jpg` — الشعار الأصلي.
- `assets/banner.jpg` — بانر المتجر الأصلي (مرجع).

## النشر

متوافق مع GitHub Pages. الفرع `main`. لا يحتوي على backend.

## ملاحظات هامة

- لا يوجد موقع فعلي حالياً — تم وضع placeholder "قريباً" مع ترك البنية جاهزة لإضافة Google Maps لاحقاً.
- لا يوجد منتج أو سعر وهمي.
- لا توجد ميزات مقاطعة وهمية.
- العروض سيتم إضافتها لاحقاً عبر وسائل التواصل.
